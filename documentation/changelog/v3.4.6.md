## 🆕 Nuevas Funcionalidades

### 1. Sistema de Alertas Automáticas (AlertsSystem)

**Archivo**: `app/Services/Attendance/AlertsSystem.php` (675 líneas)

#### Características:
- ✅ Generación automática de alertas desde LegalComplianceChecker
- ✅ 14 métodos públicos para gestión completa
- ✅ Prevención de alertas duplicadas
- ✅ Workflow completo: PENDING → ACKNOWLEDGED → RESOLVED/DISMISSED
- ✅ Estadísticas por empleado y globales
- ✅ Metadatos flexibles en formato JSON
- ✅ Referencias legales automáticas (Art. 31, 38, 39, 48, 213)

#### Métodos Principales:
```php
createAlert()                      // Crear alerta nueva
generateAlertsFromCompliance()     // Generar desde compliance check
getEmployeePendingAlerts()         // Obtener alertas pendientes
getCriticalAlerts()                // Alertas críticas globales
getEmployeeAlertStats()            // Estadísticas de empleado
acknowledgeAlert()                 // Reconocer alerta
resolveAlert()                     // Resolver alerta
dismissAlert()                     // Descartar alerta
getGlobalAlertsSummary()           // Resumen global
cleanupOldResolvedAlerts()         // Limpieza automática
getAlertsByType()                  // Filtrar por tipo
```

#### Tipos de Alertas Soportadas:
- `EXCESO_JORNADA_DIARIA` - Excede 8 horas diarias (Art. 31)
- `EXCESO_JORNADA_SEMANAL` - Excede 48 horas semanales (Art. 31)
- `EXCESO_JORNADA_MAXIMA` - Excede 11 horas (8 reg + 3 extras)
- `TIEMPO_COMIDA_INSUFICIENTE` - Menos de 30 min almuerzo (Art. 35)
- `EXCESO_JORNADA_NOCTURNA` - Excede 7 horas nocturnas (Art. 38)
- `DIAS_CONSECUTIVOS_SIN_DESCANSO` - Más de 6 días consecutivos (Art. 48)
- `AUSENCIAS_INJUSTIFICADAS_GRAVES` - 3+ ausencias en mes (Art. 213)
- `TRABAJO_FERIADO_SIN_COMPENSACION` - Trabajo en feriado sin compensatorio
- Y más...

#### Niveles de Severidad:
- **INFO**: Información general (cerca del límite)
- **WARNING**: Advertencia (requiere atención)
- **CRITICAL**: Crítico (violación legal, acción inmediata)

## 🎯 Casos de Uso

### 1. Alerta Automática por Exceso de Jornada
```php
// Al calcular asistencia con 11 horas
$calculation = $attendanceCalculator->calculateSaveAndAlert($attendance);

// Resultado:
// - Cálculo guardado en attendance_calculations
// - LegalComplianceChecker detecta violación Art. 31
// - AlertsSystem crea alerta automática:
//   - Tipo: EXCESO_JORNADA_DIARIA
//   - Severidad: CRITICAL
//   - Metadata: {total_hours: 11, max_allowed: 8, excess: 3}
```

### 2. Consultar Alertas de un Empleado
```php
// Obtener alertas críticas pendientes
$criticalAlerts = $alertsSystem->getEmployeePendingAlerts(123, 'CRITICAL');

// Obtener estadísticas últimos 30 días
$stats = $alertsSystem->getEmployeeAlertStats(123);
// Retorna: total_alerts, critical_count, warning_count, pending_count, etc.
```

### 3. Gestionar Alertas
```php
// Reconocer alerta
$alertsSystem->acknowledgeAlert($alertId, $userId, "Revisando el caso");

// Resolver alerta
$alertsSystem->resolveAlert($alertId, "Problema corregido, empleado notificado");

// Descartar alerta falsa
$alertsSystem->dismissAlert($alertId, "Error en marcación, no aplica");
```

### 4. Procesamiento Batch con Alertas
```php

    $attendances,

    $generateAlerts = true

// - stats: {
//     total_processed: 50,

//     total_alerts_generated: 8,

//   }
```

## ⚖️ Legislación Panameña Aplicada

- **Art. 31**: Jornada ordinaria 8h/día, 48h/semana
- **Art. 35**: Tiempo de comida mínimo 30 minutos
- **Art. 38**: Jornada nocturna 6PM-6AM, máximo 7h, recargo 50%
- **Art. 39**: Horas extras +25% primeras 3h, +50% adicionales
- **Art. 48**: Descanso semanal obligatorio, máximo 6 días consecutivos, trabajo domingo/feriado +50%
- **Art. 213**: 3+ ausencias injustificadas/mes = falta grave (causal despido)

## 📝 Notas de Implementación

### Prevención de Duplicados
El sistema verifica automáticamente si ya existe una alerta similar (mismo employee_id, alert_type, date) en estado PENDING o ACKNOWLEDGED antes de crear una nueva.

### Metadata Flexible
Cada alerta puede incluir un objeto JSON con datos específicos:
```json
{
  "total_hours": 11.5,
  "max_allowed": 8,
  "hours_exceeded": 3.5,
  "risk_level": "CRÍTICO",
  "absences_count": 3,
  "threshold": 3,
  "can_be_dismissed": true
}
```

### Limpieza Automática
Se puede programar limpieza de alertas resueltas antiguas:
```php
// Eliminar alertas resueltas con más de 90 días
$deleted = $alertsSystem->cleanupOldResolvedAlerts(90);
```

### Performance
- Índices optimizados para consultas frecuentes
- Vistas pre-calculadas para dashboards
- Procesamiento batch eficiente
- Stored procedures para operaciones comunes
