**Funcionalidad**:
- SQL optimizado con JOINs: `employees` → `organigrama` → `posiciones` → `cargos` → `attendance_calculations`

- Agrupación automática por departamento

  - Total marcaciones
  - Marcaciones a tiempo
  - Marcaciones con tardanza

  - Total horas extras
  - Minutos de tardanza totales
  - Promedio horas por día
- Top 10 empleados con más tardanzas
- Detalle completo por empleado con 10 campos

**Query SQL Principal**:
```sql
SELECT
    ac.id as calculation_id,
    ac.date,
    ac.time_in,
    ac.time_out,
    ac.is_late,
    ac.is_absent,
    ac.tardiness_minutes,
    ac.total_hours,
    ac.overtime_hours,
    e.id as employee_id,
    e.employee_id as employee_code,
    e.document_id as cedula,
    CONCAT(e.firstname, ' ', e.lastname) as full_name,
    org.descripcion as departamento,
    pos.codigo as position_name
FROM attendance_calculations ac
INNER JOIN employees e ON ac.employee_id = e.id
LEFT JOIN organigrama org ON e.organigrama_id = org.id
LEFT JOIN posiciones pos ON e.position_id = pos.id
WHERE ac.date BETWEEN ? AND ?
```

#### **AttendanceController.php** (+75 líneas)
**Ubicación**: `app/Controllers/AttendanceController.php` (líneas 1556-1630)

**Método Agregado**: `punchesReport()`

**Funcionalidad**:
- Endpoint principal para generación del reporte
- 3 formatos de salida soportados:
  1. **view**: Vista web HTML con tablas DataTables
  2. **json**: Respuesta JSON para APIs
  3. **excel**: Descarga directa archivo .xlsx

**Parámetros GET**:
- `start_date` (requerido): Fecha inicio (YYYY-MM-DD)
- `end_date` (requerido): Fecha fin (YYYY-MM-DD)
- `tipo_planilla_id` (opcional): ID del tipo de planilla
- `format` (opcional): Formato salida (view/json/excel, default: view)

**Validaciones**:
- Fechas requeridas
- Rango de fechas válido (start_date ≤ end_date)
- Manejo de excepciones con try-catch
- Logging de errores automático

**Ejemplo de Uso**:
```
GET /panel/attendance/reports/punches?start_date=2025-10-01&end_date=2025-10-31&tipo_planilla_id=2&format=excel
```

**Respuesta JSON** (formato: json):

        "summary": {...},
        "by_department": {...},

}
