# V3.5.15 - Configuración de Correo Electrónico en Empresa (05-Dic-2025)

## 🎯 **Objetivo**
Agregar campos de configuración SMTP en la tabla `companies` para permitir que cada empresa configure su propio servidor de correo electrónico, eliminando la dependencia de archivos `.env` y facilitando la configuración multiempresa.

## 📝 **Ejemplo de Uso en Código**

```php
// Obtener configuración de correo desde BD
$companyModel = new \App\Models\Company();
$company = $companyModel->getCompanyConfig();

// Configurar PHPMailer
$mail->Host = $company['mail_host'] ?? $_ENV['MAIL_HOST'];
$mail->Port = $company['mail_port'] ?? $_ENV['MAIL_PORT'];
$mail->Username = $company['mail_username'] ?? $_ENV['MAIL_USERNAME'];
$mail->Password = $company['mail_password'] ?? $_ENV['MAIL_PASSWORD'];
$mail->SMTPSecure = $company['mail_encryption'] ?? $_ENV['MAIL_ENCRYPTION'];
$mail->setFrom(
    $company['mail_from_address'] ?? $_ENV['MAIL_FROM_ADDRESS'],
    $company['mail_from_name'] ?? $_ENV['MAIL_FROM_NAME']
);
```

## 📚 **Referencias**

- **Puerto 587 (TLS)**: Conexión STARTTLS, inicia sin cifrar y luego upgrade
- **Puerto 465 (SSL)**: Conexión SSL/TLS implícita desde el inicio
- **Puerto 25**: Sin cifrado, solo para servidores locales/legacy
- **Puerto 2525**: Alternativo no estándar (Mailtrap, MailHog)
