**Ubicación**: `app/Views/components/navbar.php`

- `renderLicenseDropdown()`: Renderiza el HTML del dropdown (líneas 225-291)

**Características**:
- 📊 Información mostrada:
  - **Empresa**: Nombre de la compañía
  - **RUC**: Número de identificación fiscal
  - **Licencia**: Clave de licencia (formato PINN + 10 dígitos)
  - **Vencimiento**: Fecha de expiración y días restantes

- 🎨 **Indicadores Visuales (Badges)**:
  - 🟢 Verde (`badge-success`): ≥30 días restantes
  - 🟡 Amarillo (`badge-warning`): 7-29 días restantes
  - 🔴 Rojo (`badge-danger`): <7 días restantes

- 🔍 **Textos Contextuales**:
  - "X días" para licencias activas
  - "Hoy expira" para día de vencimiento
  - "Expirada" para licencias vencidas
  - "N/A" si no hay información disponible

- 🎯 **Lógica Inteligente**:
  - Solo se muestra para tenants (oculto para sistema principal con `license='default'`)
  - Cálculo automático usando `DateTime::diff()` desde `$_SESSION['license_expiration']`
  - Iconos FontAwesome para cada campo (building, id-card, key, calendar-times)

**Diseño Responsivo**:

## 🐛 Bugs Corregidos

### 1. **Error Fatal: `Call to undefined method Database::inTransaction()`**

**Problema**:
```
Fatal error: Call to undefined method App\Core\Database::inTransaction()
in WizardController.php on line 385
```

**Causa**:
- Método `inTransaction()` no existe en clase `Database` personalizada
- Solo existe en PDO nativo, no en el wrapper

**Solución**:
```php
// ❌ ANTES (líneas 383-388)
try {
    error_log("Estado transacción: " . ($this->db->inTransaction() ? 'ACTIVE' : 'INACTIVE'));
} catch (Exception $dbCheckEx) {
    error_log("Error verificando transacción: " . $dbCheckEx->getMessage());
}

// ✅ DESPUÉS
// Eliminado completamente - No se usa método inexistente
```

**Impacto**: Error crítico en producción resuelto
