**Funciones de Animación**:
```javascript
// Flag global para controlar animación inicial
window.employeesTableIsInitialLoad = true;

// Función global para animar filas del DataTable
window.animateEmployeesTableRows = function() {
    // Verificar que GSAP esté disponible
    if (typeof gsap === "undefined") return;

    const rows = $("#employeesTable tbody tr");
    if (rows.length === 0) return;

    // Asegurar que las filas estén ocultas
    gsap.set(rows, { opacity: 0, y: 0 });

    if (window.employeesTableIsInitialLoad) {
        // Primera carga: animación más elaborada
        gsap.set(rows, { y: 20 });
        gsap.to(rows, {
            opacity: 1,
            y: 0,
            duration: 0.4,
            stagger: 0.05,
            ease: "power2.out",
            clearProps: "all"
        });

        // Animar controles de paginación
        gsap.to(".dataTables_info, .dataTables_paginate", {
            opacity: 1,
            duration: 0.5,
            delay: 0.3
        });

        window.employeesTableIsInitialLoad = false;
    } else {
        // Recargas/filtros: fade rápido
        gsap.to(rows, {
            opacity: 1,
            duration: 0.3,
            stagger: 0.02,
            ease: "power1.out",
            clearProps: "all"
        });
    }

    // Animar iconos de acciones
    setupEmployeeActionButtonAnimations();
};
```

**Animaciones de Botones de Acción**:
```javascript
function setupEmployeeActionButtonAnimations() {
    if (typeof gsap === "undefined") return;

    const badges = $("#employeesTable .badge");
    const buttons = $("#employeesTable .btn-sm");
    const icons = $("#employeesTable .btn-sm i");

    // Animar badges de estado
    badges.each(function(index) {
        gsap.from(this, {
            scale: 0,
            duration: 0.4,
            delay: index * 0.02,
            ease: "back.out(2)"
        });
    });

    // Hover effects en botones de acción
    buttons.off("mouseenter.gsap mouseleave.gsap").on({
        "mouseenter.gsap": function() {
            if (!$(this).prop("disabled")) {
                gsap.to(this, {
                    scale: 1.15,
                    duration: 0.2,
                    ease: "power2.out"
                });
            }
        },
        "mouseleave.gsap": function() {
            gsap.to(this, {
                scale: 1,
                duration: 0.2,
                ease: "power2.out"
            });
        }
    });

    // Animación para iconos dentro de botones
    icons.off("mouseenter.gsap").on("mouseenter.gsap", function() {
        if (!$(this).closest(".btn").prop("disabled")) {
            gsap.to(this, {
                rotation: 360,
                duration: 0.5,
                ease: "power2.inOut"
            });
        }
    });
}
```

## 📊 **Feature 2: Innova Export System**

### **Descripción**
Sistema completo de exportación de planillas procesadas a formato de texto plano (fixed-width) para integración con el ERP INNOVA. Genera archivos con estructura jerárquica de 3 tipos de registros.

### **Componentes Implementados**

#### 1. **InnovaExportService** ✅
**Archivo**: `app/Services/InnovaExportService.php` (433 líneas)

**Métodos Principales**:

1. **`generateExportFile($payrollId)`** - Método principal
   - Obtiene datos de la planilla
   - Genera contenido del archivo
   - Guarda archivo en directorio exports/innova
   - Retorna: ['success' => bool, 'file_path' => string, 'message' => string]

2. **`getPayrollData($payrollId)`** - Consulta principal planilla
   ```sql
   SELECT pc.*, tp.nombre as tipo_planilla_nombre, f.nombre as frecuencia_nombre
   FROM planilla_cabecera pc
   LEFT JOIN tipos_planilla tp ON pc.tipo_planilla_id = tp.id
   LEFT JOIN frecuencias f ON pc.frecuencia_id = f.id
   WHERE pc.id = ? AND pc.estado IN ('PROCESADA', 'CERRADA')
   ```

3. **`getPayrollDetails($payrollId)`** - Consulta detalles con empleados
   ```sql
   SELECT pd.*, e.*, org.descripcion as departamento, c.*
   FROM planilla_detalle pd
   INNER JOIN employees e ON pd.employee_id = e.id
   INNER JOIN concepto c ON pd.concepto_id = c.id
   LEFT JOIN organigrama org ON e.departamento_id = org.id
   WHERE pd.planilla_cabecera_id = ?
   ORDER BY e.departamento_id, e.id, FIELD(c.tipo_concepto, 'A', 'D', 'P')
   ```

4. **`buildFileContent($payrollData, $details)`** - Construcción del archivo
   - Agrupa empleados por departamento
   - Genera líneas tipo 1 (movimientos individuales)
   - Genera líneas tipo 2 (neto por empleado)
   - Genera líneas tipo 3 (totales por departamento + total general)
   - Calcula netos: Asignaciones - Deducciones (Patronales no afectan neto)

5. **`buildMovementLine($detail, $payrollData)`** - Tipo 1: Movimiento individual
   - Formato: Fixed-width 347 caracteres
   - Campos: Tipo, Nómina, Fechas, ID Fiscal, Nombre, Concepto, Tipo Movimiento, Cuenta Contable, Descripción, Débito, Crédito, Tipo Pago, Banco, Cuenta, Tipo Nómina, Frecuencia, Nivel 1
   - Débito/Crédito según tipo concepto:
     - Asignaciones (A) y Patronales (P): Débito
     - Deducciones (D): Crédito

6. **`buildEmployeeNetLine($employee, $netAmount, $payrollData)`** - Tipo 2: Neto empleado
   - Formato: Fixed-width 347 caracteres
   - Tipo Movimiento: 'Z'
   - Descripción: 'NETO'
   - Crédito: Neto del empleado

7. **`buildDepartmentTotalLine($deptName, $totalNet, $payrollData)`** - Tipo 3: Total departamento
   - Formato: Fixed-width 347 caracteres
   - Tipo Movimiento: 'Z'
   - Descripción: 'TOTAL {NOMBRE_DEPARTAMENTO}'
   - Crédito: Total neto del departamento

8. **`buildGeneralTotalLine($totalNet, $payrollData)`** - Tipo 3: Total general
   - Formato: Fixed-width 347 caracteres
   - Tipo Movimiento: 'Z'
   - Descripción: 'TOTAL NETO'
   - Crédito: Total neto de toda la planilla

**Métodos Auxiliares de Formato**:

9. **`formatFixedWidth($value, $length, $align, $padChar)`**
   - Trunca texto si excede longitud
   - Padding izquierda (right) o derecha (left)
   - Ejemplo: formatFixedWidth('JUAN', 20, 'left', ' ') → 'JUAN                '

10. **`formatMoney($amount)`**
    - Formato: 12 caracteres, 2 decimales, alineado derecha
    - Ejemplo: formatMoney(1250.50) → '     1250.50'

11. **`formatDate($date)`**
    - Formato: DDMMYYYY (8 caracteres)
    - Ejemplo: formatDate('2026-02-24') → '24022026'

12. **`saveFile($payrollId, $content)`**
    - Crea directorio exports/innova si no existe
    - Nombre archivo: planilla_{ID}_{YYYYMMDD_HHiiss}.txt
    - Guarda contenido con line breaks Windows (\r\n)

13. **`getFilePath($fileName)`**
    - Retorna path completo del archivo guardado
    - Usado por el Controller para enviar archivo al usuario

**Métodos Privados de Agrupación**:

14. **`groupByEmployee($details)`** - Agrupa detalles por employee_id
15. **`groupByDepartment($employeeGroups)`** - Agrupa empleados por departamento

### **Flujo de Exportación**

```
1. Usuario accede a /panel/innova-export
   ↓
2. DataTable muestra planillas PROCESADAS/CERRADAS
   ↓
3. Usuario hace clic en "Exportar a INNOVA" (planilla específica)
   ↓
4. InnovaExportController->export($id) llama InnovaExportService
   ↓
5. InnovaExportService obtiene datos planilla + detalles
   ↓
6. Agrupa empleados por departamento
   ↓
7. Genera líneas por empleado:
   ├─ Tipo 1: Cada concepto (asignaciones, deducciones, patronales)
   ├─ Tipo 2: Neto del empleado
   └─ Cálculo: Neto = Suma(Asignaciones) - Suma(Deducciones)
   ↓
8. Genera líneas totales por departamento:
   └─ Tipo 3: Total neto del departamento
   ↓
9. Genera línea total general:
   └─ Tipo 3: Total neto de toda la planilla
   ↓
10. Guarda archivo en exports/innova/planilla_X_YYYYMMDD_HHiiss.txt
    ↓
11. Envía archivo al navegador (descarga automática)
```

### **Validaciones y Manejo de Errores**

#### **Validaciones Pre-Exportación**
✅ Planilla existe y está en estado PROCESADA o CERRADA
✅ Planilla tiene detalles (conceptos procesados)
✅ Todos los empleados tienen datos completos
✅ Departamentos están asignados (default: "SIN DEPARTAMENTO")

#### **Manejo de Errores**
- ❌ Planilla no encontrada → Mensaje error + redirect
- ❌ Planilla sin detalles → Mensaje error + redirect
- ❌ Error al generar archivo → Mensaje error + logging
- ❌ Archivo no encontrado después de generar → Mensaje error + redirect
