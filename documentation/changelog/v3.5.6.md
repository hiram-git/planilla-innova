## 📋 Resumen

Esta versión implementa la sincronización manual del calendario empresarial desde la API de Base44 y unifica el calendario de vacaciones para usar el calendario empresarial como fuente única de verdad.

## 🆕 Nuevos Componentes

### 1. CalendarSyncService
**Archivo**: `app/Services/CalendarSyncService.php` (NUEVO - ~500 líneas)

Servicio para sincronización del calendario empresarial desde API Base44.

**Características**:
- Integración con API Base44 usando cURL
- Soporte para sincronización completa o por año específico
- Modo `replace`: elimina registros existentes antes de importar
- Modo `dry_run`: simulación sin modificar base de datos
- Mapeo de tipos de día (LABORAL, FERIADO, DUELO_NACIONAL, ESPECIAL)
- Logging detallado de operaciones
- Manejo robusto de errores

**Métodos Principales**:
```php
public function syncFromApi($options = [])
private function fetchCalendarFromApi()
private function processCalendarEntity($entity, $dryRun)
private function mapDayType($apiType)
private function deleteYearRecords($year)
```

**Estadísticas Rastreadas**:
- `fetched`: Registros obtenidos desde API
- `inserted`: Registros insertados
- `updated`: Registros actualizados
- `skipped`: Registros omitidos
- `deleted`: Registros eliminados (modo replace)
- `errors`: Total de errores encontrados

### 5. Tabla de Log de Sincronización

**Estructura de Tabla `calendar_sync_log`**:

| Campo | Tipo | Descripción |

| `id` | BIGINT UNSIGNED | Primary key auto-increment |
