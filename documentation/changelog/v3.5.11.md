### 1. **Permission System Restructuring** ✅

#### **app/Middleware/PermissionMiddleware.php** (~116 líneas modificadas)

**Problema Original**:
- Sistema trataba expiración de sesión y denegación de permisos de la misma forma
- Ambos casos destruían la sesión y redirigían al login
- Usuarios perdían su sesión activa al acceder a un módulo sin permisos
- No había diferenciación para requests AJAX

**Solución Implementada**:

**1. Refactorización `logoutAndRedirect()` (líneas 97-148)**:
```php
private static function logoutAndRedirect($message = null, $route = null)
{
    $isSessionExpired = isset($_SESSION['auth_error_type']) &&
                        $_SESSION['auth_error_type'] === 'session_expired';

    // For AJAX requests
    if (isset($_SERVER['HTTP_X_REQUESTED_WITH']) &&
        strtolower($_SERVER['HTTP_X_REQUESTED_WITH']) === 'xmlhttprequest') {
        http_response_code(401);
        header('Content-Type: application/json');
        echo json_encode([
            'success' => false,
            'message' => $message,
            'redirect' => $isSessionExpired ? url('panel/login') : url('panel/access')
        ]);
        exit();
    }

    // If session expired: destroy session and redirect to login
    if ($isSessionExpired) {
        session_unset();
        session_destroy();
        session_start();
        $_SESSION['error'] = $message;
        header('Location: ' . url('admin'));
        exit();
    }

    // If permission denied: keep session and redirect to access page
    if ($route) {
        $_SESSION['access_denied_module'] = $route;
        $_SESSION['access_denied_module_name'] = ucfirst(str_replace('-', ' ', $route));
    }
    $_SESSION['warning'] = $message;
    header('Location: ' . url('panel/access'));
    exit();
}
```

**Características**:
- ✅ Diferencia sesión expirada (security) vs permiso denegado (authorization)
- ✅ Manejo especial para requests AJAX (retorna JSON)
- ✅ Preserva sesión activa cuando se deniega acceso
- ✅ Guarda información del módulo denegado en sesión
- ✅ Redirecciones apropiadas según tipo de error

**2. Método `checkRolePermission()` (líneas 220-235)** - **NUEVO**:
```php
private function checkRolePermission($roleId, $menuId, $permissionType = 'read')
{
    try {
        $column = $permissionType . '_perm';
        $sql = "SELECT $column FROM role_permissions WHERE role_id = ? AND menu_id = ?";
        $stmt = $this->db->prepare($sql);
        $stmt->execute([$roleId, $menuId]);
        $result = $stmt->fetch(PDO::FETCH_ASSOC);
        return $result ? (bool)$result[$column] : false;
    } catch (\Exception $e) {
        error_log("Error checking role permission: " . $e->getMessage());
        return false;
    }
}
```

**3. Método `getMenuIdForRoute()` (líneas 237-254)** - **CORREGIDO**:
```php
private function getMenuIdForRoute($route)
{
    try {
        $route = trim($route, '/');
        $route = str_replace('panel/', '', $route);

        $sql = "SELECT id FROM menu_items WHERE url = ? AND status = 1";
        $stmt = $this->db->prepare($sql);
        $stmt->execute([$route]);
        $result = $stmt->fetch(PDO::FETCH_ASSOC);

        if ($result) {
            return $result['id'];
        }
        return null;
    } catch (\Exception $e) {
        error_log("Error getting menu ID for route: " . $e->getMessage());
        return null;
    }
}
```

**Bugs Corregidos**:
- ❌ **Fatal Error**: "Call to undefined method checkRolePermission()" - Método faltaba completamente

```php
private function getMenuItems()
{
    try {
        $db = \App\Core\Database::getInstance();
        $sql = "SELECT id, name, url, icon, description, display_order, status
                FROM menu_items WHERE status = 1 ORDER BY display_order ASC";
        $stmt = $db->prepare($sql);
        $stmt->execute();
        $menuItems = $stmt->fetchAll(PDO::FETCH_ASSOC);

        // Index by URL for easy access
        $indexedMenu = [];
        foreach ($menuItems as $item) {
            $indexedMenu[$item['url']] = $item;
        }

        return $indexedMenu;
    } catch (\Exception $e) {
        error_log("Error obteniendo menu items: " . $e->getMessage());
        return [];
    }
}
```

### 7. **Formula Validation Enhanced** ✅

#### **app/Models/Concept.php** (línea 537 modificada)

**Problema**: El validador de fórmulas rechazaba fórmulas válidas que contenían:
- ❌ Caracteres acentuados españoles (á, é, í, ó, ú, ñ, ü)
- ❌ Comentarios con `#`
- ❌ Operador OR `||`
- ❌ Saltos de línea multilínea `\r\n`

**Error Original**:
```
Error actualizando concepto ID 4: Fórmula inválida: La fórmula contiene caracteres no permitidos
```

**Ejemplo Fórmula Rechazada**:
```php
#Para el cálculo de ISR > 50000
SI(
  (SUELDO - ACUMULADOS("SEGURO_SOCIAL",FICHA,INIPERIODO,FINPERIODO)
   - ACUMULADOS("SEGURO_EDUCATIVO",FICHA,INIPERIODO,FINPERIODO)) > 50000,
  ((SUELDO - ACUMULADOS("SEGURO_SOCIAL",FICHA,INIPERIODO,FINPERIODO)
   - ACUMULADOS("SEGURO_EDUCATIVO",FICHA,INIPERIODO,FINPERIODO)) - 50000) * 0.25 + 7192.5,
  CONCEPTO("ISR002")
)
```

**Solución - Iteraciones**:

**Iteración 1**: Agregar `#` y `|`:
```php
// BEFORE
if (!preg_match('/^[A-Z0-9_.(),\s\+\-\*\/\>\<\=\!\'\";]+$/i', $formula)) {

// AFTER (Iteración 1)
if (!preg_match('/^[A-Z0-9_.(),\s\+\-\*\/\>\<\=\!\'\";#|]+$/i', $formula)) {
```

**Iteración 2**: Agregar `\r\n` para multilínea:
```php
if (!preg_match('/^[A-Z0-9_.(),\s\+\-\*\/\>\<\=\!\'\";#|\r\n]+$/i', $formula)) {
```

**Iteración 3**: Agregar caracteres acentuados + flag UTF-8:
```php
// FINAL
if (!preg_match('/^[A-Z0-9_.(),\s\+\-\*\/\>\<\=\!\'\";#|\r\náéíóúñü]+$/iu', $formula)) {
    return [
        'valid' => false,
        'message' => 'La fórmula contiene caracteres no permitidos'
    ];
}
```

**Caracteres Soportados Ahora**:
- ✅ Alfanuméricos: `A-Z`, `0-9`
- ✅ Operadores: `+`, `-`, `*`, `/`, `>`, `<`, `=`, `!`
- ✅ Delimitadores: `(`, `)`, `,`, `.`, `_`, `'`, `"`, `;`
- ✅ Espacios: ` `, `\s`
- ✅ **NUEVO**: Comentarios `#`
- ✅ **NUEVO**: Operador OR `||` (barra vertical `|`)
- ✅ **NUEVO**: Multilínea `\r\n`
- ✅ **NUEVO**: Acentos españoles `á`, `é`, `í`, `ó`, `ú`, `ñ`, `ü`
- ✅ **NUEVO**: Flag `/u` para UTF-8

## 🚀 **Deployment Instructions**

### **Pre-Deployment Checklist**:
- [ ] Backup BD producción
- [ ] Backup archivos código producción
- [ ] Verificar PHP 8.0+ instalado
- [ ] Verificar extensión PDO habilitada
- [ ] Verificar directorio `public/assets/images/` existe

### **Deployment Steps** (10-15 minutos):

1. **Upload archivos modificados**:
   ```bash
   # Via FTP/SFTP
   /app/Middleware/PermissionMiddleware.php
   /app/Controllers/Admin.php
   /app/Core/App.php
   /app/Views/wizard/crear_empresa.php
   /app/Models/Concept.php
   ```

2. **Upload archivo nuevo**:
   ```bash
   /app/Views/admin/access.php
   ```

3. **Upload imagen background**:
   ```bash
   /public/assets/images/fondo_principal.jpg
   ```

4. **Verificar permisos archivos**:
   ```bash
   chmod 644 app/Views/admin/access.php
   chmod 644 app/Middleware/PermissionMiddleware.php
   chmod 644 public/assets/images/fondo_principal.jpg
   ```

5. **Clear cache (si aplica)**:
   ```bash
   # PHP OPcache reset
   # Restart PHP-FPM o Apache
   ```

6. **Testing post-deployment**:
   - ✅ Login como usuario con permisos limitados
   - ✅ Intentar acceder a módulo sin permisos
   - ✅ Verificar redirección a `/panel/access`
   - ✅ Verificar grid módulos permitidos
   - ✅ Verificar acceso wizard `/crear-empresa`
   - ✅ Verificar background image carga
   - ✅ Probar guardar fórmula con acentos
   - ✅ Probar fórmula multilínea con comentarios

### **Rollback Plan** (5 minutos):
```bash
# Restaurar archivos desde backup
cp backup_2025-11-27/PermissionMiddleware.php app/Middleware/
cp backup_2025-11-27/Admin.php app/Controllers/
```
