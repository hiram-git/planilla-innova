# Prefacio {.unnumbered}

## Audiencia {.unnumbered}

Este manual está dirigido a tres perfiles de usuario del Sistema de Planillas
INNOVA:

- **Administradores de planilla / RRHH**: responsables del ciclo completo de
  nómina (alta de empleados, configuración de conceptos, cierre de planillas).
- **Operadores**: personal de apoyo que registra asistencias, consulta reportes
  y gestiona solicitudes de vacaciones.
- **Super Administradores**: responsables técnicos con acceso al Panel
  Backoffice para gestión multi-tenant y configuración avanzada.

Los capítulos 1 y 2 son lectura obligatoria para todos los perfiles. Los
capítulos restantes pueden consultarse según la responsabilidad asignada.

## Cómo leer este manual {.unnumbered}

1. Revise el **Capítulo 1** para entender el acceso, los roles y la navegación.
2. Siga el flujo operativo: *Empleados* → *Estructura* → *Asistencias* →
   *Planillas* → *Conceptos* → *Acumulados* → *Vacaciones* → *Liquidaciones*.
3. Use el **Apéndice E** (FAQ) ante cualquier incidente operativo.
4. El **Apéndice B** es una referencia rápida de fórmulas para operadores
   avanzados.
