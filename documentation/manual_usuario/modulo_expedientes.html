1. ¿Qué es el Módulo de Expedientes?

Sistema de gestión documental que permite clasificar y organizar todos los documentos relacionados con cada empleado en categorías y subcategorías predefinidas.

Beneficios: Organización centralizada, acceso rápido, cumplimiento normativo y auditoría simplificada.

4. Gestionar Expedientes

  1. Ir a Empleados → Expedientes (Menu ID 26).
  2. Seleccione un empleado del listado.
  3. Click en Ver Expediente para acceder a su carpeta digital.
  4. Para agregar un documento:
    • Click en + Agregar Documento.
    • Seleccione Tipo de Expediente (ej: Estudios Académicos).
    • Seleccione Subtipo (ej: Maestría).
    • Complete campos adicionales (título, institución, fecha, etc.).
    • Adjunte el archivo digital (PDF, JPG, PNG, DOC).
    • Guarde el registro.

5. Consulta y Búsqueda

  • Búsqueda por empleado: Filtre por nombre, código o departamento.
  • Filtro por tipo: Vea solo documentos de una categoría específica (ej: solo Licencias).
  • Ordenamiento: Por fecha de emisión, tipo, o fecha de carga.
  • Vista previa: Visualización rápida de documentos PDF desde el navegador.
  • Descarga: Botón para descargar el archivo original.

7. Buenas Prácticas

  • Digitalización: Escanee todos los documentos físicos importantes.
  • Nomenclatura: Use nombres descriptivos para archivos (ej: "Titulo_Maestria_JuanPerez_2023.pdf").
  • Calidad: Escaneos legibles a mínimo 300 DPI.
  • Actualización: Mantenga expedientes actualizados con documentos recientes.
  • Seguridad: Solo personal autorizado debe acceder a documentos sensibles.
  • Respaldo: Configure backups automáticos de la carpeta de expedientes.
  • Retención: Establezca políticas de retención según legislación laboral local.
