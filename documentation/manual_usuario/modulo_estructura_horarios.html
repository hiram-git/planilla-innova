Estructura Organizacional y Horarios

Posiciones/cargos/partidas/funciones, organigrama y horarios.

1. Catálogos organizativos

  • Posiciones (empresas públicas): jerarquía por puesto; usado en empleados y organigrama.
  • Cargos, Partidas, Funciones (empresas privadas): catálogos económicos/funcionales asociados al empleado.
  • Organigrama: estructura visual; se enlaza en la ficha de empleado (opcional).

Flujo recomendado: crear primero cargos/posiciones → partidas/funciones → organigrama → asignar en empleado.

2. Horarios

  1. Ir a Horarios → Nuevo.
  2. Complete: código, nombre, descripción (opcional), hora de entrada y salida.
  3. Configure almuerzo: salida y entrada (opcional) y tolerancias.
  4. Defina tolerancias por evento (antes/después) para entrada, salida, almuerzo.
  5. Guarde. El horario queda disponible para asignarlo a empleados.
CampoObligatorioUso
CódigoSíDebe ser único.
Hora entrada / salidaSíBase para tardanza y cálculo de horas.
Almuerzo (salida/entrada)NoSi se usa, impacta cálculo de omisiones/horas.
ToleranciasRecomendadoAjustan rangos aceptables de marcación.

3. Buenas prácticas

  • Definir códigos consistentes y cortos (ej. H08-17, ADM-DIURNO).
  • Usar tolerancias realistas según política interna; si se omiten, cada variación se marca como tardanza/omisión.
  • Verificar que cada empleado activo tenga horario asignado antes de procesar asistencias.
  • En empresas públicas, preferir posiciones; en privadas, cargo/partida/función según el modelo de datos.
