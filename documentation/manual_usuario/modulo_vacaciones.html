Vacaciones

Balances, solicitudes, calendario y reportes.

1. Requisitos previos

  • Empleados activos con fecha de ingreso registrada.
  • Calendario empresarial cargado (feriados/días especiales) para validaciones futuras.
  • Opcional: tipo de planilla para filtrar balances.

2. Consultar balances

  • Vista principal muestra saldo de días, días trabajados y situación laboral.
  • Incluye cargo/posición y meses trabajados para referencia.

3. Solicitudes

  1. Seleccione empleado y defina fechas de inicio/fin.
  2. Indique tipo de vacaciones (ANNUAL o COMPENSATION) y días solicitados.
  3. Estado del flujo: PENDIENTE → APPROVED o REJECTED.
  4. Se registra request_date para filtros y reportes.

4. Calendario y reportes

  • Calendario: vista de vacaciones aprobadas; filtrable por año.
  • Reportes: filtros por empleado, estado, tipo y fecha/rango de solicitud; límite de registros para rendimiento.

5. Buenas prácticas

  • Validar saldo antes de aprobar; documentar comentarios si se rechaza.
  • Usar el calendario empresarial para evitar solapes en feriados y fines de semana si aplica.
  • Exportar reportes periódicamente para control de ausentismo.
