Cómo operar cada módulo: pasos, campos, validaciones y mejores prácticas.

Cómo usar este manual

  • Revisa primero Acceso y navegación para entender roles y menús.
  • Luego entra a cada módulo según tu rol: Empleados → Estructura → Horarios → Asistencias → Planillas → Conceptos → Acumulados → Vacaciones → Liquidaciones → Acreedores → Reportes → Configuración.
  • Cada página incluye flujos paso a paso, campos obligatorios, validaciones y checklist de cierre.
