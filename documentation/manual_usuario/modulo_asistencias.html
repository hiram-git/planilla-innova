Módulo de Asistencias v3.5.19

Dispositivos/API, sincronización, cálculo, ausencias y reportes avanzados de marcaciones.

1. Requisitos previos

  • Empleados activos con código, horario y situación asignados.
  • Dispositivos registrados o API configurada.
  • Calendario empresarial cargado (para feriados y días especiales).

2. Dispositivos y API

  1. En Asistencia → Dispositivos, registre cada fuente de marcaciones (nombre, IP/host, estado).
  2. En Asistencia → Configuración API, configure credenciales API y pruebe conexión.

Tip: habilite sincronización programada (cron) para traer registros cada 15 minutos.

3. Sincronización

  • Completa: importa todo el rango disponible (uso puntual).
  • Hoy: sincroniza solo el día actual.
  • Rango: define fechas específicas.

El Historial de Sync muestra fecha/hora, dispositivo, registros importados y errores.

4. Marcaciones por día

  • Vista principal con filtros de año, mes, dispositivo o rango personalizado.
  • Estadísticas rápidas: completas, incompletas, tardanzas, ausencias.
  • Desde cada fecha se accede al detalle por empleado.

5. Cálculo y ausencias

  • AttendanceCalculator: horas trabajadas, horas extras (+25%/+50%), nocturnas, descuentos por tardanza.
  • AbsenceDetector: marca PENDIENTE/JUSTIFIED/UNJUSTIFIED; permite justificar o rechazar.
  • Reprocesar día: elimina cálculos previos y recalcula con horarios/tolerancias actuales.
  • Alertas legales: valida jornadas y feriados usando el calendario empresarial.

6. Reportes de Marcaciones NUEVO

Sistema completo de reportes de asistencias disponible en Asistencia → Reportes → Marcaciones (/panel/attendance/reports).

Formatos Disponibles

  • Vista Web: Reporte interactivo en pantalla con filtros dinámicos
  • Exportación Excel: Archivo descargable con formato profesional
  • API JSON: Endpoint para integración con otros sistemas

7. Marcaciones en kiosko

  • Acceso rápido desde la barra superior: Marcaciones.
  • Permite registrar entrada/salida manual vinculada al código de empleado.
  • Requiere horario asignado y situación activa.

8. Integración con Planillas

Los datos de asistencias se integran automáticamente con el módulo de planillas mediante:

  • 16 Funciones de Asistencias: Disponibles en el motor de fórmulas para conceptos
  • Resumen por Período: Tabla payroll_attendance_summary con estadísticas consolidadas
  • Regeneración Planillas: Al regenerar un empleado, se recalculan conceptos basados en asistencias

Funciones Principales para Fórmulas

Función Descripción Ejemplo Uso
HORAS_TRABAJADAS() Total horas regulares HORAS_TRABAJADAS() * TARIFA_HORA
HORAS_EXTRAS_25() Horas extras al 25% HORAS_EXTRAS_25() * (SUELDO/220) * 1.25
HORAS_EXTRAS_50() Horas extras al 50% HORAS_EXTRAS_50() * (SUELDO/220) * 1.50
TARDANZAS() Minutos totales de tardanza TARDANZAS() / 60 * (SUELDO/220)
SCORE_PUNTUALIDAD() Puntuación 0-100 SI(SCORE_PUNTUALIDAD() >= 95, 100, 0)
AUSENCIAS() Días sin marcación AUSENCIAS() * (SUELDO/30)

9. Checklist de Operación

  • ✓ Todos los empleados activos tienen horario y situación correcta.
  • ✓ Dispositivos y API con credenciales válidas y pruebas de conexión exitosas.
  • ✓ Calendario empresarial cargado (feriados/días especiales) para cálculos legales.
  • ✓ Sincronización programada (cron) activa para importación automática cada 15 minutos.
  • ✓ Antes de enviar a planilla, reprocesar el día si se ajustaron tolerancias u horarios.
  • ✓ Revisar reportes de marcaciones antes del cierre de planilla para justificar ausencias.
  • ✓ Validar top 10 tardanzas y gestionar excepciones antes de aplicar descuentos.
  • ✓ Verificar integración con planillas: conceptos basados en asistencias calculan correctamente.
