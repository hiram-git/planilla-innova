Módulo de Empleados

Altas, edición, bajas, importación y validaciones.

1. Requisitos previos

  • Catálogos listos: posición o cargo/partida/función, horario, situación laboral, tipo de planilla.
  • Roles/permisos: acceso a employees con crear/editar/eliminar según el rol.

2. Crear empleado

  1. Ir a Empleados → Nuevo Empleado.
  2. Complete datos básicos: código único, nombres, apellidos, documento, fecha nacimiento e ingreso.
  3. Asigne información organizacional según empresa:
    • Pública: posición (con organigrama si aplica).
    • Privada: cargo, partida, función.
  4. Seleccione horario y situación (activo/inactivo/suspendido).
  5. Defina contrato: tipo (indefinido/definido/proyecto/temporal), número, fecha inicio/fin.
  6. Configure forma de pago: efectivo, cheque o ACH; si cheque/ACH, capture banco, cuenta, tipo de cuenta.
  7. Ingrese salario individual y gastos de representación si corresponde.
  8. Adjunte foto y relaciónelo al organigrama (opcional).
  9. Guarde. El sistema valida campos obligatorios y unicidad del código.

3. Edición y bajas

  • Listado principal: búsqueda por nombre, código, documento, cargo/posición; acciones de ver, editar, desactivar.
  • Vista Empleados dados de baja: consulta y reactivación si corresponde.

4. Importar desde Excel

  1. Descargue la plantilla desde Importar desde Excel.
  2. Complete columnas obligatorias: código, nombres, apellidos, documento, fecha de ingreso, salario, horario, situación, tipo de planilla.
  3. Opcionales: correo, marca_asistencia, permite_horas_extras, datos bancarios.
  4. Cargue el archivo; el sistema valida duplicados y formatos antes de insertar.

5. Campos principales y reglas

CampoObligatorioNotas
Código empleadoSíÚnico; se usa en deducciones y asistencia.
Nombres/ApellidosSíTexto.
DocumentoSíValidar formato local.
Fecha ingresoSíBase de antigüedad y acumulados.
Posición o Cargo/Partida/FunciónRecomendadoVisible según tipo de empresa.
HorarioSí para asistenciasUsado para cálculo de tardanzas/horas extras.
SituaciónSíActivo/Inactivo/Suspendido (afecta planillas y filtros).
Tipo de planillaSíSe usa para filtros y cálculos.
Contrato (tipo/fechas)CondicionalObligatorio fecha fin si no es indefinido.
Forma de pagoSíMuestra campos bancarios según selección.
Salario individualSíBase de conceptos y acumulados.

6. Checklist rápido

  • Código único y situación = Activo.
  • Horario asignado si usa asistencias.
  • Contrato completo (fecha fin si aplica) y forma de pago coherente con datos bancarios.
  • Tipo de planilla correcto para filtros y cálculo.
