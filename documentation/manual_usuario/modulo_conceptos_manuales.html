Módulo de Conceptos Manuales v3.5.11

Gestión de conceptos personalizados por empleado, integrados automáticamente en planillas.

1. ¿Qué son los Conceptos Manuales?

Sistema que permite crear conceptos de planilla específicos para empleados individuales, sin necesidad de definirlos en el catálogo global de conceptos.

Diferencia clave: Los conceptos del catálogo global aplican a todos los empleados según fórmulas. Los conceptos manuales son personalizados: cada empleado puede tener montos, unidades o referencias únicos.

Ejemplo de uso: Bono especial por proyecto, compensación temporal, deducción específica, ajuste único, incentivo personalizado.

2. Características Principales

  • Vinculación directa: Cada concepto manual se asocia a un empleado específico
  • Basado en catálogo: Utiliza conceptos existentes del catálogo global como base
  • Valores personalizables: Monto, unidad y referencia únicos por empleado
  • Integración automática: Se aplican automáticamente durante la regeneración de planillas
  • Vigencia controlada: Estado activo/inactivo para control temporal
  • Trazabilidad completa: Registro de creación y última modificación

4. Crear un Concepto Manual

  1. Ir a Empleados → Conceptos Manuales.
  2. Click en + Nuevo Concepto Manual.
  3. Complete el formulario:
    • Empleado: Seleccione del dropdown (búsqueda por nombre/código).
    • Concepto: Seleccione del catálogo global de conceptos.
    • Monto: Ingrese el valor numérico (decimales permitidos).
    • Unidad (opcional): Cantidad de unidades si aplica.
    • Referencia (opcional): Nota descriptiva (máx 255 caracteres).
    • Estado: Marque como activo (checked) o inactivo (unchecked).
  4. Guarde el registro.
Importante: El concepto manual solo se aplicará en planillas futuras o al regenerar planillas existentes. No modifica planillas ya procesadas y cerradas.

5. Gestión de Conceptos Manuales

Listado Principal

Vista con tabla DataTables mostrando todos los conceptos manuales configurados:

  • Columnas: Empleado, Concepto, Monto, Unidad, Referencia, Estado, Acciones
  • Búsqueda global: por nombre empleado, código concepto, referencia
  • Filtrado por estado: Activo/Inactivo
  • Ordenamiento por cualquier columna
  • Paginación automática (10, 25, 50, 100 registros)

Acciones Disponibles

  • Ver: Muestra detalles completos en modal (read-only).
  • Editar: Permite modificar monto, unidad, referencia, estado.
  • Eliminar: Borra el concepto manual (requiere confirmación).
Nota: No se puede cambiar el empleado ni el concepto base después de crear el registro. Para eso debe eliminarlo y crear uno nuevo.

6. Integración con Planillas

¿Cómo se aplican?

Los conceptos manuales se procesan automáticamente durante la regeneración de empleados en una planilla:

  1. El sistema busca todos los conceptos manuales activos del empleado
  2. Para cada concepto manual encontrado:
    • Verifica que el concepto base esté en el catálogo
    • Crea un registro en planilla_detalle
    • Asigna el monto, unidad y referencia personalizados
    • Marca el origen como concepto manual
  3. Los conceptos manuales se suman/restan según su naturaleza (INGRESO/DEDUCCION)

Flujo de Procesamiento

1. Usuario regenera empleado en planilla
2. Sistema limpia conceptos previos del empleado
3. Sistema aplica conceptos del catálogo global (fórmulas)
4. Sistema aplica conceptos manuales activos
5. Calcula totales (ingresos - deducciones)
6. Actualiza planilla_empleado

10. Buenas Prácticas

  • Referencias descriptivas: Use el campo referencia para documentar el motivo del concepto.
  • Revisión periódica: Revise mensualmente conceptos manuales activos para desactivar los temporales.
  • Nomenclatura consistente: Use referencias claras (ej: "Bono Proyecto X - Ene 2026").
  • Control de vigencia: Desactive conceptos cuando ya no apliquen en lugar de eliminarlos (mantiene historial).
  • Montos negativos: Use valores negativos para deducciones (ej: -50.00 para descuento).
  • Validación pre-cierre: Revise conceptos manuales antes de cerrar planilla definitivamente.
  • Documentación externa: Mantenga registro externo de aprobaciones de bonos/ajustes especiales.
  • Conceptos base apropiados: Use conceptos del catálogo con naturaleza correcta (INGRESO/DEDUCCION).

11. Preguntas Frecuentes

¿Puedo aplicar múltiples conceptos manuales al mismo empleado?

Sí, un empleado puede tener tantos conceptos manuales como sea necesario. Cada uno se procesa independientemente.

¿Qué pasa si desactivo un concepto manual?

No se aplicará en futuras regeneraciones de planilla. Las planillas ya procesadas no se ven afectadas.

¿Puedo usar el mismo concepto base para varios empleados?

Sí, el mismo concepto del catálogo (ej: BONO_ESPECIAL) puede usarse como base para conceptos manuales de diferentes empleados con montos distintos.

¿Los conceptos manuales afectan acumulados (XIII mes, vacaciones)?

Depende de la configuración del concepto base. Si el concepto base está marcado para acumular, sí afectará los acumulados.

¿Qué pasa si elimino un concepto del catálogo que usa un concepto manual?

El concepto manual quedará inactivo pero no se eliminará. Se recomienda eliminar o reasignar los conceptos manuales primero.
