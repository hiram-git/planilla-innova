Acceso y Dashboard

Roles, permisos, navegación y métricas iniciales.

1. Inicio de sesión

  1. Ingrese usuario y contraseña en la pantalla de login del panel.
  2. El sistema valida CSRF y credenciales; al aprobar, redirige a Dashboard.
  3. Para cerrar sesión, use el menú de usuario (esquina superior derecha).

Licencia: si el tenant no es “default”, el dropdown de licencia muestra empresa, RUC, clave y días restantes.

2. Roles y permisos (referencia rápida)

RolPermisos típicosUso sugerido
Super AdminTodo el sistema, configuración y seguridad.Soporte/Liderazgo TI.
AdministradorPlanillas, empleados, asistencias, conceptos, reportes.RRHH/Payroll Manager.
OperadorConsulta y operaciones acotadas (empleados, asistencias, reportes).Analistas/Operación.
Solo lecturaConsulta de reportes y listados.Auditoría/Visores.

3. Navegación

  • Barra superior: selector de tipo de planilla (persistente en sessionStorage), reloj en vivo, acciones rápidas (nuevo empleado/horario/posición), acceso a Marcaciones y dropdown de licencia.
  • Sidebar: módulos agrupados: Dashboard, Gestión de personal, Control de asistencia, Reportes, Nómina/Planillas, Acumulados, Liquidaciones, Vacaciones, Acreedores/Deducciones, Configuración.
  • Migas de pan y avisos: cada vista incluye breadcrumbs y notificaciones Toastr para éxitos/errores.

4. Dashboard

  • Métricas clave: empleados activos, planillas procesadas, monto total, conceptos activos (filtrables por tipo de planilla).
  • Accesos rápidos: nueva planilla, buscar empleado, procesar nómina, generar reportes.
  • Alertas: mensajes de permiso, estado de sesión y avisos de licencia.
