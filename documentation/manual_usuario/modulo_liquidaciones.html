Liquidaciones

Cálculo por motivo, aprobación y planilla de liquidación · v3.5.22

Novedades v3.5.22

  • Rutas separadas: CRUD en /liquidation/* y reportes en /liquidation-reports/* (principio de responsabilidad única).
  • Cálculo LIQ007 mejorado: ajuste de rangos de fechas + totales mensuales precisos + logging detallado para auditoría.
  • Acumulados por tipo: método getAccumulatedTypesForLiquidation() que consolida XIII mes y otros acumulados automáticamente.
  • Totales mensuales: método getMonthlyTotalsForLiquidation() para calcular base mensual exacta por período.
  • Visualización: singular/plural dinámico (“1 año” / “2 años”, “1 día” / “2 días”) en la vista de detalle.

1. Requisitos

  • Empleado activo con datos completos (fecha de ingreso, salario, situación).
  • Motivo definido y fecha de terminación.
  • Frecuencia “LIQUIDACION” creada/activa para planillas de liquidación.
  • Acumulados del empleado actualizados (XIII mes, vacaciones) para cálculos proporcionales precisos.

2. Crear liquidación

  1. Ir a Liquidaciones → Crear.
  2. Seleccione el empleado y la fecha de terminación.
  3. Elija el motivo: renuncia, despido justificado/injustificado, jubilación, mutuo acuerdo.
  4. El sistema calcula automáticamente:
    • Prima de antigüedad.
    • Indemnización (según causa).
    • Preaviso.
    • XIII mes proporcional (concepto LIQ007 con totales mensuales precisos).
    • Vacaciones pendientes y proporcionales.
  5. Revise los valores calculados y guarde.

3. Planilla de liquidación

  • Las liquidaciones pueden generar una planilla dedicada con frecuencia de liquidación.
  • Se procesa y cierra igual que las planillas regulares, con sus reportes PDF y Excel.
  • Al generar la planilla se asocian automáticamente los acumulados del empleado.

4. Reportes (sección separada)

Los reportes se encuentran en Liquidaciones → Reportes (ruta /liquidation-reports/):

  • Certificado de liquidación PDF con cálculos detallados.
  • Comprobante de pago para el empleado (firma y sello).
  • Reporte contable para registros financieros.
  • Exportación Excel para análisis adicional.

5. Checklist

  • Fecha de terminación correcta y motivo seleccionado.
  • Salario y antigüedad revisados antes de aprobar.
  • Verificar que los acumulados XIII mes estén actualizados para LIQ007.
  • Exportar/reportar tras aprobar para firma y archivo.
  • Si corresponde, crear la planilla de liquidación y procesarla.
