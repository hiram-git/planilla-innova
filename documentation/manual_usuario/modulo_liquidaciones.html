Liquidaciones

Cálculo por motivo, aprobación y planilla de liquidación.

1. Requisitos

  • Empleado activo con datos completos (fecha de ingreso, salario, situación).
  • Motivo definido y fecha de terminación.
  • Frecuencia “LIQUIDACION” creada/activa para planillas de liquidación.

2. Crear liquidación

  1. Ir a Liquidaciones y elegir Crear.
  2. Seleccione empleado y fecha de terminación.
  3. Elija motivo: renuncia, despido justificado/injustificado, jubilación, mutuo acuerdo.
  4. El sistema calcula automáticamente:
    • Prima de antigüedad.
    • Indemnización (según causa).
    • Preaviso.
    • XIII mes proporcional.
    • Vacaciones pendientes/proporcionales.
  5. Revise los valores y guarde.

3. Planilla de liquidación

  • Las liquidaciones pueden generar una planilla dedicada con frecuencia de liquidación.
  • Se procesa y cierra igual que las planillas regulares, con sus reportes.

4. Reportes

  • Certificado de liquidación PDF (detallado con cálculos).
  • Comprobante de pago para el empleado.
  • Reporte contable para registros financieros.

5. Checklist

  • Fecha de terminación correcta y motivo seleccionado.
  • Salario y antigüedad revisados antes de aprobar.
  • Exportar/reportar tras aprobar para firma y archivo.
  • Si corresponde, crear la planilla de liquidación y procesarla.
