## 🔧 Cómo Usar

### **Opción 1: Template Base (Estático)**
```
1. Descargar template_empleados_planilla_innova.xlsx
2. Eliminar filas de ejemplo (2-6)
3. Llenar con datos reales
4. Ajustar IDs según su base de datos
5. Importar en el sistema
```

### **Opción 2: Template Dinámico**
```
1. Ir a Panel > Empleados > Importar Excel
2. Clic en "Template Dinámico"
3. Archivo se genera con IDs actuales
4. Llenar datos directamente
5. Importar sin ajustar IDs
```

## ✅ Ventajas de Cada Opción

### **Template Base:**
- ✅ Disponible offline
- ✅ Ejemplos completos para aprender
- ✅ No requiere acceso al sistema
- ⚠️ Requiere ajustar IDs manualmente

### **Template Dinámico:**
- ✅ IDs siempre actualizados
- ✅ Listo para usar directamente
- ✅ Integrado con el sistema
- ⚠️ Requiere acceso al sistema

## 🎉 Resultados

Ambos templates están **100% funcionales** y producen el mismo resultado final. La elección depende de tu preferencia de trabajo:

- **Para aprender**: Template Base con ejemplos
- **Para producción**: Template Dinámico actualizado
